# StudySphere — by Navdeep Kaur

StudySphere is a premium, responsive student learning and academic productivity website built with HTML5, CSS3 and Vanilla JavaScript.

## Files
- index.html — website structure
- style.css — complete visual design and responsive layout
- script.js — all interactive features
- assets/ — add images, screenshots or a real resume here

## Features
- Subject search and category filters
- Subject detail modal
- Saved subjects using localStorage
- Interactive five-question quiz
- Quiz score history and best-score dashboard
- Study planner with add/edit/delete/complete
- LocalStorage persistence
- Goal tracker with progress controls
- Progress dashboard
- Achievement system
- Pomodoro-style focus timer
- Study technique modals
- Dark/light mode with saved preference
- Mobile navigation
- Scroll progress indicator
- Back-to-top button
- Contact form validation with mailto fallback
- Responsive design
- Reduced-motion support

## Run locally
Double-click `index.html` and open it in Chrome, Edge or Firefox.

## Customise
Open `script.js` and replace:
`navdeep.kaur@example.com`
with the real email address if you want the contact form to open the correct mail application.

Replace any project text, subject data, colours or content directly in `index.html`, `style.css` and `script.js`.

## Publish
### GitHub Pages
1. Create a GitHub repository.
2. Upload all files while keeping the same structure.
3. Enable GitHub Pages from repository settings.
4. Select the main branch/root folder.
5. Open the generated Pages URL.

### Netlify
Upload the complete project folder to Netlify's deployment interface.

## Important
This project intentionally uses demo/local data. It does not claim to have a backend database, AI service, real academic records or real external opportunities.
